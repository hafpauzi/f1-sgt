So.. I kept going to AI to ask when's the race in Singapore time so i had it coded for specifically my notion pages. If you're a Singaporean, feel free to embed my widget onto your notion!! 

## Features 
- 🇸🇬 Automatic SGT conversion
- ⏳ Live countdown
- 🏁 Next F1 session tracking
- 📅 Full race weekend schedule

## Summary of what i've learnt from JSON:
- Finding F1 API race schedule --> Jolpica's documentation
- To find the current season data --> /ergast/f1/current/next
- So literally paste https://api.jolpi.ca/ergast/f1/current/next.json

- To find the race name, use race.raceName
- To find the next race or upcoming one, the code find something like next race endpoint, so i use /ergast/f1/current/next.json
